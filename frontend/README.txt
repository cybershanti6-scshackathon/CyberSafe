CYBERSURE FRONTEND
===================

Files:
- index.html
- dashboard.html
- rpp.html
- nes.html
- web-security.html
- ai-assistant.html
- reports.html
- styles.css
- app.js

RUN:
1. Extract the ZIP.
2. Open the folder in VS Code.
3. Install/use Live Server.
4. Right-click index.html -> Open with Live Server.
5. Navigate using the CyberSure sidebar.

IMPORTANT:
- The frontend uses demo/mock assessment results.
- Real security scanning and backend APIs are not implemented here.
- PDF buttons use jsPDF when available and fall back to the browser print dialog.
- The same CyberSure logo, sidebar, navigation, theme and responsive behavior are shared across every page.
- The project uses the Glacier-inspired palette and responsive design.

PROJECT MODULES IMPLEMENTED:
Dashboard
NES
RPP
Web Security
AI Assistant
Reports

NAP and XCODE were not added because those module names/requirements are not defined in the current CyberSure project files/context. They should not be invented without a specification.
